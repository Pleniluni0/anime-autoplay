# Anime AutoPlay — Chrome Web Store Description

## Short Description (132 chars max)

Autoplay for anime sites — countdown, intro skip, fullscreen, and player memory. Binge-watch like Netflix.

## Detailed Description

**Anime AutoPlay** turns your favorite anime and donghua streaming sites into a Netflix-like experience. When an episode ends, a countdown overlay appears — just sit back and watch as it automatically plays the next episode.

### ✨ Features

- **Autoplay countdown**: Configurable 3–15 second countdown before advancing to the next episode. Includes "Watch now" and "Cancel" buttons.
- **Intro/opening skip**: Define start and end timestamps. Choose between a manual floating button or fully automatic skip.
- **Ending/credits skip**: Show the countdown overlay earlier, N seconds before the episode ends.
- **Player/server memory**: Remembers which streaming server you used and auto-selects it when switching episodes.
- **Fullscreen toggle**: One-click fullscreen activation via a prominent overlay prompt.
- **Auto-pause**: The countdown pauses when you switch tabs — never miss a moment.
- **DNS prefetch & prefetch**: Preloads the next episode for faster navigation.
- **Keyboard shortcuts**: N (next episode), S (skip intro), C (cancel countdown), G (cut the countdown to 2 s), F (fullscreen), P (picture-in-picture), ← → (seek 5 s), + / − (adjust the ending skip).
- **Night mode**: Choose how many more episodes to watch, then autoplay stops by itself — no episodes running all night if you fall asleep.
- **Watch history**: The last episode you watched of each series, grouped by site. Only episodes that actually advanced after the countdown are recorded, so visiting a page by mistake never overwrites it. Stored locally.
- **Spanish / English**: The interface follows your browser language and can be changed from the popup.

### 🎯 Supported Sites

- AnimeAV1
- AnimeFLV
- SeriesDonghua
- MundoDonghua
- DonghuaLife
- JKAnime

### ▶️ How It Works

1. **Start watching** any episode on a supported site.
2. When the episode ends, a **countdown overlay** appears in the corner.
3. The extension automatically **navigates to the next episode**.
4. On the new page, a **fullscreen prompt** appears — click once to activate fullscreen and audio.
5. The video auto-plays. **Intro/opening** is skipped automatically (or via a button).
6. Rinse and repeat. 🎬

### 🔒 Privacy

This extension collects **no data**. All settings and your watch history are stored locally in your browser. No analytics, no tracking, no third-party services. Full privacy policy available in the repository.
